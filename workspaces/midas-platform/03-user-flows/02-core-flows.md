# Midas v1 — Core User Flows

## Flow 1: Onboarding (New User → First Paper Trade)

```
[Landing Page]
    │
    ▼
[Sign Up] ── email + password + MFA setup
    │
    ▼
[Choose Model Portfolio] ── Growth (14% vol) / Balanced (10%) / Conservative (6%)
    │                        Each shows: historical return, max drawdown,
    │                        regime behavior, cost drag, sleeve breakdown
    ▼
[Link IBKR Account] ── OAuth flow (paper account default for onboarding)
    │                   "We never move your money. You click every trade."
    │                   Show security reassurance: no withdrawal access, read-only + order-preview
    ▼
[Dashboard] ── Shows: latest published signal for chosen portfolio,
    │          current regime (normal/cautious/turbulent),
    │          what the signal would mean for your current IBKR holdings
    │          (computed CLIENT-SIDE from position sync)
    ▼
[First Approval Card] ── The latest signal, pre-populated
    │                     "Here's what the Growth portfolio recommends this week"
    │                     Per-trade: ticker, direction, quantity, estimated cost
    │                     Total cost estimate, expected portfolio impact
    ▼
[Approve + Execute] ── Biometric confirm → order submitted to IBKR
    │                   Confirmation: "3 orders placed. Watch IBKR for fill."
    ▼
[Post-Trade Summary] ── What you now own, how it maps to the model,
                        link to debate chat: "Want to understand why?"
```

**Key UX principle**: The onboarding flow must give the user permission to trust the system. Every step explains "why" and "what happens." No black boxes.

**Paper trading default**: First 2 weeks are paper trading unless user explicitly opts out. Reduces fear of commitment and builds trust.

## Flow 2: Weekly Signal (Normal Regime — Alex doesn't need to do anything)

```
[Sunday 7 PM ET] ── Signal generated by strategy engine
    │
    ▼
[Signal Published] ── Written to impersonal signals table
    │                 (model_portfolio_id, timestamp, allocations, reasoning)
    ▼
[Push Notification] ── "Growth portfolio update: minor rebalance. 2 trades."
    │                   Tap to review.
    ▼
[Approval Card] ── Grouped rebalance card
    │   ┌───────────────────────────────────────────┐
    │   │ Growth Portfolio — Weekly Rebalance        │
    │   │                                           │
    │   │ Regime: Normal (confidence: 82%)           │
    │   │                                           │
    │   │ ☑ Buy 15 shares GLD  ($2,847)  cost: $1.02│
    │   │ ☑ Sell 8 shares TLT  ($832)    cost: $0.68│
    │   │                                           │
    │   │ Net cost: $1.70   Impact: +0.3% gold exp. │
    │   │                                           │
    │   │ [Why this?]  [Approve All ✓]  [Skip]      │
    │   └───────────────────────────────────────────┘
    ▼
[Approve All] ── Biometric → orders sent to IBKR
    │
    ▼
[Confirmation] ── "2 orders placed. Estimated fills within market open."
```

**Key**: In normal regime, this is the entire weekly interaction: push → card → swipe → done. < 30 seconds.

## Flow 3: Regime Flip (Turbulent — System FREEZES and ASKS)

```
[Regime Ensemble] ── HY OAS spike + VIX3M backwardation + drawdown > 8%
    │                Transition: Normal → Turbulent
    │                2-day hysteresis confirmed
    ▼
[Auto-Trading Frozen] ── No new signals published until user decides
    ▼
[URGENT Push Notification] ── "⚠ Market regime changed to TURBULENT. Trading paused."
    │                          "Review the situation and tell us what to do."
    ▼
[Regime Change Screen]
    │   ┌───────────────────────────────────────────┐
    │   │ ⚠ REGIME: TURBULENT                       │
    │   │                                           │
    │   │ What changed:                              │
    │   │ • Credit spreads widened 120bps (2-week)   │
    │   │ • VIX term structure inverted              │
    │   │ • S&P 500 down 8.2% from peak              │
    │   │                                           │
    │   │ Historical parallels: Mar 2020, Sep 2008   │
    │   │                                           │
    │   │ If we do nothing: current portfolio stays   │
    │   │ If we go defensive: move to cash + bonds    │
    │   │   (estimated cost: $47.30)                  │
    │   │                                           │
    │   │ [Debate This] [Go Defensive] [Hold Current]│
    │   └───────────────────────────────────────────┘
    ▼
    ├── [Debate This] → Opens debate chat with regime context pre-loaded
    │     User: "Is this really as bad as 2008?"
    │     AI: "The credit spread widening is comparable in speed but not
    │          magnitude. In 2008, HY OAS hit 2100bps; we're at 650.
    │          [cite: signal_regime_20260412_hy_oas]. However, the
    │          VIX inversion pattern matches early-stage crises in 4
    │          of 6 historical events. [cite: backtest_run_2847]."
    │
    ├── [Go Defensive] → Generates defensive rebalance signal → approval card
    │
    └── [Hold Current] → Regime acknowledged, no action. Logged in audit trail.
                         System checks again next market close.
```

**Key**: This is the "don't trade without my permission" requirement. The system detects, explains, and waits. The user decides. The debate agent is available to help them think through it.

## Flow 4: Debate (User-Initiated, Any Time)

```
[User opens Debate Chat]
    │
    ▼
[Chat Interface]
    │
    User: "Why are we so heavy in commodities?"
    │
    ▼
[DebateAgent processes]
    │   1. Calls fetch_current_recommendation → gets current sleeve weights
    │   2. Calls fetch_signal(latest) → gets the reasoning behind commodity weight
    │   3. Calls fetch_backtest_run(commodity_sleeve) → gets regime-conditional returns
    │   4. Composes grounded response
    ▼
    AI: "Commodities are at 18% in the Growth portfolio, up from 12% last month.
         The allocator increased exposure because:
         1. Commodity momentum (6-month) is top-3 across all sleeves
            [cite: signal_momentum_20260407_commodities]
         2. In the current regime (normal, late-cycle), commodities have
            historically returned 11.2% annualized vs 7.8% for equities
            [cite: backtest_run_3102_regime_normal_late]
         3. The cost to reach this weight was $4.12 in transaction costs
            [cite: cost_model_20260407_rebal]

         Do you disagree with any of these inputs?"
    │
    User: "I think commodities are topping. I'd rather be in gold specifically."
    │
    ▼
    AI: "That's a directional view I can test. If we had held GLD-only instead
         of the broad commodity sleeve (DJP+GSG+GLD) over the last 12 months:
         - Return: +14.2% (GLD) vs +11.8% (broad) [cite: backtest_run_3103]
         - Volatility: 16.4% vs 12.1% — GLD-only concentrates risk
         - In the last 3 commodity-topping episodes (2011, 2018, 2022), GLD
           underperformed broad commodities by 3-7% in the subsequent 6 months
           [cite: backtest_run_3104_topping]

         The model's broad allocation is designed to avoid this kind of
         concentration risk. But you know your conviction level better than
         I do. Want me to show what the portfolio looks like with GLD-only?"
```

**Key**: The agent defends its position with data. It doesn't capitulate ("you're right, let's go all-in on gold!"). It also doesn't refuse ("I can't do that"). It shows the evidence and lets the user decide. Every number has a citation ID that resolves to a real computation.
