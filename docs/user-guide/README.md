## Who should read what

- **First time user?** Read `01` → `02` → `03` → `04` in order.
- **Experienced investor, impatient?** Skip to `05`, `06`, `07` for the strategy mechanics.
- **Want to understand the AI?** Read `09` and `10` together.
- **Setting up production?** Read `02`, `12`, `14`, `16`.
- **Something broke?** Start at `15`.
- **Legal questions?** Read `17`.

## Reading time

Full guide: ~45 minutes. Each chapter: 2-5 minutes.
